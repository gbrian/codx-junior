## 📄 Overview and Purpose

**Goal of Free Software:**
When discussing "free software," the focus is on *freedom*, not price. The General Public Licenses are intended to guarantee user freedom to share, change, and distribute all versions of a program (as stated in the Preamble).

**The AGPL's Unique Functionality:**
Most general public licenses might fail when software is used over networks. Critically, while the GNU General Public License permits creating modified versions run on network servers without releasing the source code, **the GNU AGPL requires that the operator of a network server must provide the source code of the modified version running there to the users of that server.** This mechanism ensures public use of a modification results in public access to its source code (Preamble).

### Conveying Non-Source Forms (Binary/Object Code)

If you convey an object code work, you **must** also provide the Corresponding Source under one of these methods:

*   **Option A:** Physical product accompanied by the Corresponding Source on a durable physical medium.
*   **Option B:** Physical product accompanied by a written offer for at least three years to give either (1) a copy of the Corresponding Source, or (2) access to copy the Corresponding Source from a network server, both at no charge (Section 6b).
*   **Option D (Network/Digital):** Offering access to the object code and offering equivalent instant access to the Corresponding Source in the same manner through the same place. If this location is a network server, you must ensure the source remains available for as long as necessary (Section 6d).

### Remote Network Interaction (The AGPL Mandate)

If your modified version supports interaction with users remotely through a computer network, you **must** prominently offer all users an opportunity to receive the Corresponding Source of your modification by providing access to it from a network server at no charge (Remote Network Interaction; Use with the GNU General Public License, Section 13).

## 🛠️ For Developers: Applying This License

If you develop or modify a program and wish for it to be free software under these terms:

*   **Licensing Notice:** It is recommended that comprehensive notices are attached (e.g., "This program is free software: you can redistribute it and/or modify it under the terms of the GNU Affero General Public License...") (How to Apply These Terms).
*   **Source Availability:** If your software can interact with users remotely through a computer network, ensure that an accessible mechanism exists for users to download source code. For instance, a web application could display a "Source" link leading to an archive of the code. Sections 13 and Preamble mandate this availability.
*   **Legal Recommendations:** It is advised to get your employer or school (if applicable) to sign a "copyright disclaimer" for the program (How to Apply These Terms).
