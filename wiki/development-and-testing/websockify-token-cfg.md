# Development and Testing: Websockify Configuration

This documentation outlines the configuration for the remote screen preview and sharing environment used within the `codx-junior` project.

## Overview
The project environment utilizes Websockify to bridge VNC connections. The following configurations are defined:

### Screen Preview
*   **Purpose:** Provides a view-only interface for the screen.
*   **Configuration:** `CODX-SCREEN-PREVIEW: 127.0.0.1:5901`

### Screen Sharing
*   **Purpose:** Facilitates shared access to the screen environment.
*   **Configuration:** `CODX-SCREEN-SHARED: 127.0.0.1:5902`
