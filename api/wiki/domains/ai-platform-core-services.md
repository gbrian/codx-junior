# AI Platform Core Services

## Overview
The AI Platform Core Services provide the foundational backend API layer for managing complex interactions involving large language models (LLMs) and AI infrastructure. This cluster is responsible for coordinating project workflows, handling chat sessions, and executing code via integrated engines. Key functionalities include managing model interactions (specifically leveraging vLLM), providing comprehensive project lifecycle management, administering sophisticated analytics tools for usage tracking, cost prediction, and performance monitoring. It serves as the central intelligence hub for any application requiring deep AI integration, ranging from basic conversational interfaces to complex code execution pipelines.

The domain manages various aspects of the AI life cycle:
*   **Model Interaction:** Providing API endpoints wrappers (`ai_model.py`) and connecting to specialized model serving engines (`vllm_cpu_ai.py`).
*   **Workflow Management:** Structuring projects, chat sessions, and resource allocation (`workspaces.py`, `chat.py`, `projects.py`).
*   **Analytics & Logging:** Tracking usage metrics, processing tokens, storing logs, and calculating costs across the system (`analytics-*`, `logs.*`).
