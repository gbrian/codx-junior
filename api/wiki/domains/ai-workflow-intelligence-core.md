# AI Workflow & Intelligence Core

## Overview
The AI Workflow & Intelligence Core is the backend infrastructure responsible for orchestrating advanced, intelligent workflows within a modern workspace application. This core module acts as the primary integration point for various generative AI capabilities, moving beyond simple API calls to manage complex business logic and state transitions.

Its primary functions include:

1.  **Workflow Management:** Managing multi-step user workflows by integrating conversational chat engines (`api/chat.py`) with robust code execution environments (`engine/code_engine.py`).
2.  **State Persistence:** Maintaining comprehensive, project-specific state management across different user sessions and modules (e.g., `workspaces.py`, `projects.py`).
3.  **Intelligence Layer:** Abstracting AI model interactions via wrappers like `ai_model.py` and handling various backend LLM implementations (e.g., `vllm_cpu_ai.py`).
4.  **Observability & Analytics:** Providing deep insights into the platform's usage by integrating dedicated logging, metrics tracking, and cost prediction services (`analytics/`, `rawlogger.py`). This analytics system is sophisticated enough to process interaction data using LLMs for advanced auditing and billing.

The domain serves as a highly critical layer that abstracts away the complexity of interacting with external AI APIs, unifying chat logic, computing execution, and usage telemetry into a single cohesive unit.
