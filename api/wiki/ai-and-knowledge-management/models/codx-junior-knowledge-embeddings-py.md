## Embeddings Models Documentation

This library provides structures for generating vector embeddings, supporting both local, self-contained models and hybrid solutions that integrate external AI services with a local fallback mechanism. The core functionalities are encapsulated in two main classes: `LocalEmbeddingsModel` and `HybridEmbeddingsModel`.

### LocalEmbeddingsModel

The `LocalEmbeddingsModel` is designed for generating embeddings locally and is fully self-contained, thus eliminating dependence on external AI services (as stated in the module description). It uses `sentence-transformers` under the hood.

**Initialization (`__init__`)**
Initializes the model by accepting an optional `model_name`.
*   **Argument:**
    *   `model_name` (`str`, optional): The HuggingFace model identifier to use. Defaults to `"all-MiniLM-L6-v2"`. This default model is noted for providing a "good balance between speed and quality for semantic search" and has 384 dimensions.

**Properties**
*   **`model` (`@property`)**: Implements lazy loading. It loads the actual `SentenceTransformer` model only upon first access, attempting to download the specified model name (see *Load Model* section).
*   **`embedding_dim` (`@property`)**: Returns the calculated dimension of the embeddings generated by the loaded model. Requires accessing the `model` property to trigger loading (_"Lazy-load the embeddings model on first access."_).

**Methods**
*   **`embed_query(text: str) -> List[float]`**
    Generates a vector embedding for a single input query string. It includes input validation and handles potential errors during encoding.
*   **`embed_documents(texts: List[str]) -> List[List[float]]`**
    Generates embeddings for an entire list of document text strings (`List[str]`). This method also includes checks to ensure the inputs are valid lists of strings.

### HybridEmbeddingsModel

The `HybridEmbeddingsModel` provides a resilient approach to embedding generation. It attempts to use an initialized external AI embeddings service first, but is designed to gracefully failover and utilize the local `LocalEmbeddingsModel` if the primary AI service encounters an error (_"falls back to the local sentence-transformer model if needed."_).

**Initialization (`__init__`)**
Initializes the hybrid handler.
*   **Argument:**
    *   `ai_embeddings` (`Any`, optional): An optional callable representing the external AI embeddings object (e.g., from an OpenAI AI service).
    *   `local_model_name` (`str`, optional): The name of the local fallback model, defaulting to `"all-MiniLM-L6-v2"`.

**Functionality**
The class determines if it is using a local fallback by checking if `ai_embeddings` was provided; if not, `self._use_local` is set to `True`.

*   **`embed_query(text: str) -> List[float]`**
    Embeds a single query string. The process involves attempting the AI service first. If any exception occurs during the AI call, it logs a warning and automatically switches the internal state (`self._use_local = True`) to fall back to the local model's `embed_query` method.
*   **`embed_documents(texts: List[str]) -> List[List[float]]`**
    Embeds multiple documents. Similar to `embed_query`, it attempts the AI service first and, if an error is caught, logs a warning and falls back to utilizing the local model's `embed_documents` method.
