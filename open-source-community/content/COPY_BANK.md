## 2. Boilerplate

**25 words**
> codx-junior is an open-source workspace where Kanban, AI agents, dev containers, review and
> per-user AI budgets live in one browser tab.

**50 words**
> codx-junior is an open-source workspace for hybrid AI + human software teams. Kanban boards
> where every card is a chat, agents with project tools, dev containers, team chat, code review
> and per-user AI budgets live in one browser tab. Self-host the engine under AGPL-3.0, or hire
> the managed team to execute your roadmap.

**100 words**
> codx-junior is an open-source workspace for hybrid AI + human software teams. It puts the whole
> project in one browser tab: a Kanban board where every card is a chat, AI agents that search
> the repo, patch files, run containers and open diffs, team channels where humans and agents are
> the same kind of member, code review, and per-user AI budgets metered in cxjcoins. The engine is
> self-hosted and provider-agnostic — Ollama, LiteLLM, vLLM or any OpenAI-compatible API — under
> AGPL-3.0. Teams that would rather not run it themselves can hire the managed team, which works
> inside the same workspace.

## 3. Feature blurbs (site cards, 20–25 words)

| Feature | Blurb |
| --- | --- |
| Kanban | Every card is a chat: moving a task starts an agent with your repo as context. |
| Agents | Profiles set the model, the tools and the standards. Diffs land for review. |

| Knowledge | Your repo indexed into Milvus so agents find the right files before acting. |
| Workspaces | Dev containers from templates, routed through Traefik. *(beta badge)* |

| Review | Branches, diffs and PR views with AI comments next to the change. |
| Providers | Any OpenAI-compatible provider, per-purpose models, MCP servers per project. |
| API | REST, Socket.IO and an OpenAI-compatible endpoint for your own clients. |
| Company mode | An org chart of departments, teams and missions where agents are members. |

## 8. Words we use / avoid

| Use | Avoid |
| --- | --- |
| workspace, task, agent run, diff, budget, self-hosted | platform (vague), solution, synergy, ecosystem |
| supervised autonomy | fully autonomous |
| active beta | production-ready |
| one tab, one place | all-in-one (overused on PH) |
| cost per task | cost savings (unmeasured) |
| open source, AGPL-3.0 | free (ambiguous) |
| humans approve every change | human-in-the-loop (jargon) |
