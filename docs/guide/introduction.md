## The hybrid model

codx-junior is built around one idea: AI does the volume, humans keep the direction.

* **AI agents** search the codebase, write and patch files, run containers, generate images and documentation, and review changes.
* **Humans** define the work on the Kanban board, pick the profiles and models the agents use, review every diff and pull request, and talk to each other and to the agents in the same channels.
* **Budget** is visible at all times: AI usage is metered in tokens and cxjcoins per user and model, next to the human hours you plan.
