# Development tools

## Desktop

The desktop is a window manager inside the browser. Open chats, workspace apps, the Kanban board and settings as tabs or windows, group them, and save the layout as a **view** you can reopen or share.

## Coder

**Coder** is VS Code in the browser, running in a [workspace](/features/workspaces). It supports VS Code extensions and, when Docker is available, containers.

## Virtual desktop and preview

A virtual desktop (noVNC or Kasm VNC) lets you test your app like a user would, with a real browser. The **preview** panel shows the project's preview URL next to the conversation.

## File browser

Browse, search, preview, upload, download, create, rename, move, copy, archive and delete project files from the UI, and add them to a chat.

## Project scripts

Define named bash scripts per project (build, test, run). Scripts can run in the background, restart automatically when they stop, and be launched from the UI.

## Logs

Admins can follow the API and system logs, the AI raw logs and the chat logs from **Settings → Miscellaneous**.
