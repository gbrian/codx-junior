# Kanban and tasks

The Kanban board is where humans plan the work and hand it to the AI.

![Kanban](/images/NOV2025/codx-junior-kanban.png)

## Boards

Each project can have several boards. A board has a name, a description, an optional remote URL and its columns (for example *Backlog*, *To Do*, *In Progress*, *Done*). Boards can be bookmarked and switched from the sidebar.

## Tasks are chats

Every card on a board is a [chat](/features/chats-and-agents). Opening a card opens the conversation, so a task can be discussed with the team, refined into a specification and executed by an agent, all in one place.

A task can have:

* a status, tags and assigned users,
* profiles and a model,
* linked files and attachments,
* checklists,
* **sub-tasks**, created by hand or generated by the AI from the parent task.

## Views

Switch between the **board** view (columns and cards), a **grid** view with filters, and a **tree** view of tasks and sub-tasks. The Kanban panel is also available next to the conversation in [vibe coding](/features/vibe-coding).

## Templates

Mark a chat as a template to reuse it when creating new tasks.
