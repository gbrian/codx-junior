# Features

codx-junior is a single workspace that covers the whole life of a software project: plan the
work, build it with AI agents, run it in dev containers, talk it over with your team, keep the
context and stay in budget. This section documents every feature in detail.

## Plan and organise

| Feature | Summary |
| --- | --- |
| [Chats and agents](/features/chats-and-agents) | Project-aware chats with modes, sub-chats, attachments and a tool-using agent loop. |
| [Kanban and tasks](/features/kanban) | Boards and columns where every card is a chat with sub-tasks, checklists and assignees. |
| [Profiles](/features/profiles) | Reusable instructions that set the model, tools and coding standards. |

## Build

| Feature | Summary |
| --- | --- |
| [Vibe coding](/features/vibe-coding) | The conversation, the live file changes and the running app side by side. |
| [Knowledge (RAG)](/features/knowledge) | Projects indexed into Milvus so the AI finds the right context before it acts. |
| [@codx mentions](/features/mentions) | Write `@codx` in any file and codx-junior edits, explains or improves it in place. |
| [Wiki](/features/wiki) | AI-maintained project documentation, updated as the code changes. |

## Run and collaborate

| Feature | Summary |
| --- | --- |
| [Workspaces](/features/workspaces) | Docker Compose dev containers with VS Code, a virtual desktop and your apps. |
| [Teams and messenger](/features/teams) | Teams, categories, channels and direct messages shared by humans and agents. |
| [Development tools](/features/development-tools) | Desktop window manager, Coder, file browser, project scripts and logs. |

## Ship and control

| Feature | Summary |
| --- | --- |
| [Git and code review](/features/code-review) | Branches, commits, diffs, pull-request views and GitHub issues. |
| [AI providers and models](/features/ai-providers) | Any OpenAI-compatible provider, with per-purpose models and MCP servers. |
| [Budget and analytics](/features/budget-and-analytics) | cxjcoins, wallets, spending limits and usage dashboards. |
| [Users and security](/features/users-and-security) | Roles, project permissions, GitHub OAuth and forward-auth for apps. |

## Extend

| Feature | Summary |
| --- | --- |
| [Plugins](/features/plugins) | Python plugins that extend the UI and the API. |
| [API](/features/api) | The REST API, Socket.IO events and the OpenAI-compatible endpoint. |
